##  Projects

### Task 1: Iris Flower Classification

**Objective:** Build machine learning models to classify iris flowers into different species using their measurements.

**Technologies:** Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn

**Key Features:**
- Data exploration and preprocessing.
- Logistic Regression classification.
- Decision Tree classification.
- Model evaluation using accuracy and confusion matrices.
- Model comparison and decision boundary visualization.

**Results:**
- Logistic Regression Accuracy: 93.33%
- Decision Tree Accuracy: 93.33%

**Project Files:** [View Task 1](./DataScience-Task1-IrisFlowerClassification/)

### Task 2: Unemployment Analysis with Python

**Objective:** Analyze unemployment trends in India, compare regional differences, and examine unemployment before and during the COVID-19 period.

**Technologies:** Python, Pandas, Matplotlib

**Key Features:**
- Unemployment trend analysis over time.
- Regional unemployment comparison.
- Before and during COVID-19 analysis.
- Urban versus rural unemployment comparison.
- Trends across the three regions with the highest average unemployment.
- Correlation analysis of employment indicators.

**Key Findings:**
- Highest average unemployment region: Tripura (28.35%).
- Lowest average unemployment region: Meghalaya (4.80%).
- Average unemployment before COVID-19: 9.51%.
- Average unemployment during COVID-19: 17.77%.

**Project Files:** [View Task 2](./DataScience-Task2-UnemploymentAnalysis/)

### Task 3: Car Price Prediction with Machine Learning

**Objective:** Develop a machine learning model to estimate the selling price of a used car based on its features.

**Technologies:** Python, Pandas, Matplotlib, Scikit-learn, Joblib

**Key Features:**
- Used-car dataset preprocessing.
- Duplicate removal and car age feature engineering.
- Selling price distribution analysis.
- Average selling price comparison by fuel type.
- Random Forest Regression model training.
- Model evaluation using Mean Absolute Error (MAE) and R² score.
- Sample car price prediction.
- Saving the trained model for reuse.

**Model Results:**
- Algorithm: Random Forest Regressor
- R² Score: 0.5155
- Mean Absolute Error: ₹1,50,088.47
- Sample predicted price: ₹6,30,800

These results represent the current model performance on the selected dataset and test split.

**Project Files:** [View Task 3](./DataScience-Task3-CarPricePrediction/)
