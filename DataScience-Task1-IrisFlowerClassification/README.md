
# Iris Flower Classification using Machine Learning

## Project Overview
This project uses supervised machine learning to classify Iris flowers into Setosa, Versicolor, and Virginica using Python and Scikit-learn.

## Objectives
- Explore and analyze the Iris dataset.
- Check missing values and data distributions.
- Visualize flower measurements using pairplots and box plots.
- Train and evaluate machine learning models.
- Compare Logistic Regression and Decision Tree classifiers.

## Dataset
- Total samples: 150
- Input features: 4
- Target classes: 3
- Training samples: 120
- Testing samples: 30

## Technologies Used
- Python
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn
- Jupyter Notebook

## Machine Learning Models
1. Logistic Regression
2. Decision Tree Classifier

## Model Evaluation

| Model | Accuracy | Correct Predictions |
|---|---:|---:|
| Logistic Regression | 93.33% | 28 out of 30 |
| Decision Tree | 93.33% | 28 out of 30 |

Both models achieved the same accuracy on the current test dataset. The notebook includes classification reports, precision, recall, F1-scores, and confusion matrices.

## Visualizations
- `confusion_matrix.png` — Logistic Regression confusion matrix.
- `confusion_matrix_decision_tree.png` — Decision Tree confusion matrix.
- `model_comparison.png` — Model accuracy comparison.
- `decision_boundary.png` — Logistic Regression decision boundary.

The notebook also includes exploratory data analysis, pairplots, and box plots.
